# ClaudeUsageWidget

macOS 메뉴바에서 Claude의 실시간 사용량을 한눈에 확인하세요. 
API 요청 한도를 실시간으로 모니터링하여 효율적인 작업 환경을 만들어줍니다.

## 🚀 주요 기능
- **다양한 스타일 지원**: 링, 바, 도트 등 취향에 맞는 다양한 방식으로 사용량 시각화
- **리셋 타이머**: 사용량이 100%일 때, 남은 사용 가능 시간(Reset Time)을 즉시 확인
- **상세 정보**: 메뉴바 클릭 시 팝업을 통해 상세 사용 현황(5시간/주간) 확인 가능
- **개인화 옵션**: 메뉴바 아이콘 설정 및 남은 시간 표시 토글 기능 제공
- **자동 실행**: 맥 재부팅 시 앱 자동 시작 지원 (설정에서 활성화)

## 🛠 기술 스택
- **Language**: Swift
- **UI**: SwiftUI (AppKit 통합)
- **Security**: Keychain (데이터 보호)
- **Framework**: ServiceManagement (로그인 시 자동 실행)

## 📋 사용 방법
1. 터미널에서 `claude login` 명령어를 통해 로그인을 완료합니다.
2. 앱을 실행하면 자동으로 로그인 정보를 가져와 사용량을 표시합니다.
3. 설정 창에서 스타일, 새로고침 주기, 자동 실행 여부를 맞춤 설정하세요.

## 🔒 보안
- 사용자의 인증 토큰은 macOS **Keychain(키체인)**에 안전하게 저장됩니다.
- 코드 내에 어떠한 API 키나 민감한 정보도 하드코딩되어 있지 않습니다.
